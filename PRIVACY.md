# ReConfig Privacy Policy

Effective date: 1 September 2026

ReConfig’s gameplay, visual, configuration, and HUD features run locally. The optional Social features use the ReConfig Cloudflare Worker so friends can exchange requests, messages, presence, and server invitations across Minecraft servers.

## Data ReConfig processes

When Social is used, ReConfig sends your Minecraft username and UUID, a randomly generated authentication token, friend requests and friendship relationships, message content and reply references, online presence timestamps, a one-way hash of the current server address, and the full server address only when you explicitly send a server invitation. ReConfig also requests public Minecraft profile and skin information. The service does not collect Microsoft passwords, payment information, private Minecraft access tokens, or inventory/gameplay contents.

Cloudflare may process technical request information such as IP addresses and diagnostic logs under its own service policies. ReConfig uses the stored data only to provide its social features, prevent abuse, troubleshoot failures, and operate the service. It does not sell personal data or use it for advertising.

## Storage and sharing

Social data is stored in Cloudflare D1 and is shared only with the ReConfig users involved in the relevant friendship, conversation, or invitation. Public profile data may be obtained from Mojang/Minecraft services or a fallback public profile provider. Data is retained while needed to provide the service and maintain account relationships. Removing a friend removes the friendship but does not automatically erase existing messages.

## Your choices

You must accept this policy before using ReConfig. You can avoid sending new Social data by not using Friends, Messages, or server invitations, and uninstalling ReConfig stops future client requests. You may request access or deletion through the project’s GitHub issue tracker without posting private authentication data: https://github.com/duv14/ReConfig/issues

This policy may change when ReConfig’s data practices change. A new policy version will require consent again in the mod.
